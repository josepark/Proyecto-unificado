# Datos de referencia para importación

Coloque aquí el Excel oficial de MITRE ATT&CK Enterprise, por ejemplo:

- `enterprise-attack-v19_1.xlsx`

El script `./desplegar.sh` lo importa automáticamente si el catálogo de amenazas
está vacío (menos de 100 entradas) y encuentra un `.xlsx` en esta carpeta.

Descarga: https://attack.mitre.org/resources/attack-data-and-tools/
